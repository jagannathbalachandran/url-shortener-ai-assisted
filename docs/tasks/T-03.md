# T-03: Create short link

## Intent
Expose an API endpoint that validates a long URL, generates a secure short code,
saves the link, and returns the short URL.

## Context
- Depends on: T-02 (repository, CodeCollisionError), ADR-001 D1 (random 7-char
  base62 via `secrets`, unique constraint, max 5 retries), D2 (new code per create)
- Requirements: FR-1; Security (http/https only, max 2,048 chars, non-guessable
  codes); Reliability (link saved before the short URL is returned)

## Scope
In scope:
- FastAPI app factory (`create_app()`) with per-request DB session wiring
- `POST /api/v1/links` with body `{"url": "..."}`
  → 201 `{"code", "short_url", "original_url", "created_at"}`
- Code generator: 7 chars, base62 alphabet, from `secrets`; injectable so tests
  can control it
- LinkService: validate → generate code → save → commit; on CodeCollisionError
  retry with a new code, max 5 attempts, then raise a domain error
- Named constants for code length, alphabet and max retries
- README: how to run the service (uvicorn) and where the Swagger docs are

Out of scope:
- Redirect and link-details endpoints (T-04)
- Custom error format, rate limiting, health checks (T-05)

## Constraints
- Layering per CLAUDE.md: route → service → repository; no DB or business
  logic in the route handler
- The stored URL must be exactly what the user submitted (validation must not
  silently rewrite it, e.g. by adding a trailing slash)
- No new dependencies

## Acceptance criteria
1. Valid http/https URL → 201 with a 7-char base62 code; short_url = BASE_URL + "/" + code.
2. The link is committed to the database before the response is sent
   (test: readable via the repository after the request).
3. Rejected with 422: `javascript:`, `data:`, `file:`, `ftp:` schemes; missing host;
   empty or malformed input; URLs over 2,048 chars.
4. Submitting the same URL twice returns two different codes (ADR-001 D2).
5. Collision handling: with a generator forced to repeat a code, the service
   retries and succeeds with the next code.
6. Retry exhaustion: if all 5 attempts collide, the API returns 503 (not a raw 500).
7. Stored original_url equals the submitted URL exactly.
8. Unit tests (generator, validation, service retry logic) and integration tests
   (endpoint through to the DB), including the failure cases above.
